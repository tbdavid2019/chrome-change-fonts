繁體中文版

✨ v2.2.2 更新重點（雲端字體字重調整與雙層級保護）

  • 新增「雲端字重」微調選單：選用 Google Fonts 雲端字體（單一字體或分流模式非 CJK 皆適用）時，可自由選擇 跟隨網頁預設、300 細體、400 標準、500 中等、600 半粗 或 700 粗體，即時預覽區與目標網頁同步套用；選用本機字體時會安全停用。
  • 完整支援清單與智慧層級保護：前 8 款等寬程式與高易讀字體完整支援 300–700（Atkinson Hyperlegible 與 Anonymous Pro 提供 400 / 700）；只調整內文基準字重，保留 h1–h6 標題、strong、b、th 粗體層級與圖示字體。
  • 內建 10 款置頂雲端字體（免裝字體・按需載入）：cloud 分組位於選單最上方，支援按需載入（referrerpolicy="no-referrer"）與「網站規則管理頁」單站字重記憶。
JetBrains Mono (300–700) Fira Code (300–700) Google Sans Code (300–700) Geist Mono (300–700) Source Code Pro (300–700) Intel One Mono (300–700) Lilex (300–700) Atkinson Hyperlegible Mono (300–700) Atkinson Hyperlegible (400/700) Anonymous Pro (400/700)

📖 4 步驟快速上手指引

  1. 開啟擴充功能彈窗：點擊瀏覽器右上角 333 圖示（版本更新後首次開啟會自動於背景分頁打開本頁，不打斷您的操作）。
  2. 挑選字體與雲端字重：從最上方「雲端字體」挑選免安裝字體並於「雲端字重」微調粗細，或從下方「本機字體」選擇電腦已安裝字體；需要中英混排時可切換至「CJK / 英數分開」。
  3. 啟用與即時預覽：勾選「啟用字體替換」，並可直接在彈窗下方預覽區輸入文字確認字體與字重效果。
  4. 管理個別網站：可切換「僅此網站」指定特定網站專用字體與字重，或勾選「此網站不生效」（圖示會顯示 OFF 徽章），並可隨時點「網站清單」統一管理規則。
貼心提醒：少數網站（例如 GitHub、銀行或企業內部系統）啟用了嚴格的 Content-Security-Policy (font-src / style-src)，瀏覽器會阻擋第三方雲端字體載入，屆時該網站會安全退回系統字體；若想在該類網站也強制換字體，建議在電腦安裝字體後從「本機字體」選單套用。

🇺🇸 English · Release Highlights & Quick Start Guide

English Version

✨ What's New in v2.2.2

  • Cloud Font Weight Control: When a Cloud Google Font is active (in either Single font or CJK / Latin split → Non-CJK), adjust body text weight between Auto, 300 Light, 400 Regular, 500 Medium, 600 SemiBold, and 700 Bold, with live preview in the popup. Automatically disabled for local system fonts.
  • Hierarchy & Compatibility Preserved: 8 curated monospace cloud fonts support full 300–700 (while Atkinson Hyperlegible & Anonymous Pro enable 400 / 700). Only base body weight is adjusted—h1–h6 headings, strong, b, th, and icon fonts keep their visual hierarchy.
  • 10 Curated Cloud Fonts Listed at the Top: Instant Google Fonts loading with referrerpolicy="no-referrer", zero extra permissions, and per-site weight overrides in Site list.
JetBrains Mono (300–700) Fira Code (300–700) Google Sans Code (300–700) Geist Mono (300–700) Source Code Pro (300–700) Intel One Mono (300–700) Lilex (300–700) Atkinson Hyperlegible Mono (300–700) Atkinson Hyperlegible (400/700) Anonymous Pro (400/700)

📖 4-Step Quick Start Guide

  1. Open the Popup: Click the 333 toolbar icon (on the first click after an extension update, this page opens quietly in a background tab without closing your popup).
  2. Choose Your Font & Cloud Weight: Pick an instant cloud font from the top Cloud Fonts group and fine-tune Cloud weight, or choose any locally installed font below; switch to CJK / Latin split to set separate fonts for CJK and Latin text.
  3. Enable & Preview: Check Enable font replacement and test both typeface and weight directly inside the live preview box.
  4. Customize Per-Site Rules: Use This site only for per-site font & weight overrides, toggle Disable on this site (shows an OFF badge), or open Site list to manage all rules in one place.
Note on Strict-CSP Websites: A few high-security websites (such as GitHub or banking/enterprise portals) enforce strict font-src / style-src Content-Security-Policy headers that block external Google Fonts. On those sites, the page safely falls back to system fonts; to override fonts there, install the font on your OS and select it from the System Fonts group.
